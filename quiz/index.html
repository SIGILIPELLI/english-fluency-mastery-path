    Analyse a spoken answer¶

    Write analyse(transcript, seconds) to compute the word count, words per minute, filler-word count and filler rate (percent), and the type-token ratio (distinct words divided by total words). It's the kind of measurement you can run on your own recorded talk.

    Starter code

    import re

FILLERS = {"um", "uh", "er", "like", "basically", "actually"}

def analyse(transcript, seconds):
    # return a dict with: words, wpm (rounded), fillers (count of FILLERS), filler_rate (% rounded to 1 d.p.)
    # and ttr (distinct words / total words, rounded to 2 d.p.). Words = letters and apostrophes, lowercased.
    return {}

talk = ("Um I would like to talk about a person who has influenced me. Basically my aunt, "
        "she taught me to be patient, and actually she taught me to listen. Like when I was "
        "young I was very impatient but she showed me how to listen carefully.")
print(analyse(talk, 30))

    Expected output

    {'words': 46, 'wpm': 92, 'fillers': 5, 'filler_rate': 10.9, 'ttr': 0.7}
    Show solution and explanation 
    import re

FILLERS = {"um", "uh", "er", "like", "basically", "actually"}

def analyse(transcript, seconds):
    words = re.findall(r"[a-zA-Z']+", transcript.lower())
    fillers = [w for w in words if w in FILLERS]
    wpm = len(words) / (seconds / 60)
    ttr = len(set(words)) / len(words)           # lexical variety (type-token ratio)
    return {
        "words": len(words),
        "wpm": round(wpm),
        "fillers": len(fillers),
        "filler_rate": round(100 * len(fillers) / len(words), 1),
        "ttr": round(ttr, 2),
    }

talk = ("Um I would like to talk about a person who has influenced me. Basically my aunt, "
        "she taught me to be patient, and actually she taught me to listen. Like when I was "
        "young I was very impatient but she showed me how to listen carefully.")
print(analyse(talk, 30))

    Measuring pace, fillers and lexical variety turns 'I think I did okay' into evidence you can improve against. These are rough proxies, not official band scores. Verified by running the solution.

    Check an IELTS essay's basics¶

    Write check_essay(text, task): Task 1 needs at least 150 words and an overview word (overall, in summary, to summarise); Task 2 needs at least 250 words and at least four paragraphs separated by blank lines. Return a list of problems or ['ok'].

    Starter code

    import re

def check_essay(text, task):
    # task1 needs >= 150 words and an overview word (overall / in summary / to summarise);
    # task2 needs >= 250 words and at least 4 paragraphs (separated by blank lines).
    # return a list of problem strings, or ["ok"]
    return []

essay = ("Some people think museums should be free. I partly agree.\n\n"
         "Free entry increases access for everyone. " * 5 + "\n\n"
         "However, funding is a concern. " * 5)
print(check_essay(essay, "task2"))
report = "The chart shows sales in four regions. " * 8 + "Overall, the north was highest."
print(check_essay(report, "task1"))
print(check_essay("The graph rises.", "task1"))

    Expected output

    ['under word count (105/250)']
['under word count (61/150)']
['under word count (3/150)', 'no overview sentence']
    Show solution and explanation 
    import re

def check_essay(text, task):
    minimum = {"task1": 150, "task2": 250}[task]
    words = re.findall(r"[A-Za-z']+", text)
    paragraphs = [p for p in re.split(r"\n\s*\n", text.strip()) if p.strip()]
    problems = []
    if len(words) < minimum:
        problems.append(f"under word count ({len(words)}/{minimum})")
    if task == "task2" and len(paragraphs) < 4:
        problems.append("needs introduction, body paragraphs and conclusion (at least 4 paragraphs)")
    if task == "task1" and not re.search(r"\b(overall|in summary|to summarise|to summarize)\b", text.lower()):
        problems.append("no overview sentence")
    return problems or ["ok"]

essay = ("Some people think museums should be free. I partly agree.\n\n"
         "Free entry increases access for everyone. " * 5 + "\n\n"
         "However, funding is a concern. " * 5)
print(check_essay(essay, "task2"))
report = "The chart shows sales in four regions. " * 8 + "Overall, the north was highest."
print(check_essay(report, "task1"))
print(check_essay("The graph rises.", "task1"))

    Meeting length and structure requirements is the floor, not the ceiling: the band depends on task response, coherence, vocabulary and grammar. This checker only catches basic omissions. Verified by running the solution.
