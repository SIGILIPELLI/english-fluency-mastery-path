# 10 · Capstone — Full IELTS Mock Test Self-Administration & Band Score Self-Assessment

This capstone combines everything from Levels 1-4 into one exercise:
administer a complete, timed IELTS mock test to yourself, then
self-assess it honestly using official-style band descriptors. This
module gives you the timing, structure, and a self-assessment
framework to do that rigorously.

## 1. IELTS test structure and timing (for self-administration)

| Section | Duration | Format |
|---|---|---|
| Listening | 30 minutes of audio, 4 sections, 40 questions | Plus time to transfer/check answers (10 min on paper test; built into the 30 min on the computer-delivered test) |
| Reading | 60 minutes | 3 passages, 40 questions total |
| Writing | 60 minutes | Task 1 (~20 min, 150+ words) + Task 2 (~40 min, 250+ words) |
| Speaking | 11-14 minutes | 3 parts: introduction/general questions, a 2-minute individual long turn (with 1 minute prep), and a two-way discussion |

Academic Writing Task 1 asks you to describe a chart, graph, table, or
diagram; General Training Task 1 asks you to write a letter. Both
share the same Task 2 essay format.

## 2. Self-administering the mock realistically

| Rule | Why it matters |
|---|---|
| Use a real timer, no pausing | The real exam allows no extra time; practicing under true time pressure is the point |
| Do all four sections in one sitting if possible | Tests stamina, which is a real factor in the actual exam |
| Record the Speaking section | You cannot self-assess speaking fluency accurately from memory alone |
| Use unseen material | Reusing a practice test you've already seen invalidates the Reading/Listening timing results |

## 3. Band descriptors — a practical self-assessment scale

| Band | General description |
|---|---|
| 9 | Expert user — full operational command, appropriate, accurate, fluent |
| 8 | Very good user — fully operational command, occasional unsystematic inaccuracies |
| 7 | Good user — operational command, occasional inaccuracies and inappropriate usage |
| 6 | Competent user — generally effective command despite some inaccuracies |
| 5 | Modest user — partial command, copes with overall meaning in most situations |

Use this scale honestly against your own recorded Speaking and written
Writing responses rather than against how confident you felt while
producing them — confidence and accuracy are not the same thing.

## 4. Self-assessment checklist by section

| Section | Self-check questions |
|---|---|
| Listening | Did I lose points to spelling/plural errors rather than comprehension? Did a distractor ("actually, I meant...") catch me? |
| Reading | Did I confuse False and Not Given? Did I run out of time on the last passage? |
| Writing Task 1 | Did I select and report the *key* features/trends, not just list every number? |
| Writing Task 2 | Did I directly and fully answer every part of the question? Is my position clear from the introduction? |
| Speaking | Did my Part 2 long turn run close to the full 2 minutes? Did I self-correct naturally or freeze on errors? |

## 5. Worked example — a self-assessment note after a mock test

> "Listening: 35/40 correct — three losses were spelling errors on
> otherwise correct answers, one was a genuine mishearing in Section
> 4. Fix: slow down on transferring answers, double-check spelling of
> proper nouns. Speaking: recorded Part 2, ran only 1:10 of the 2
> minutes — under-length. Content was fine but I stopped too early
> instead of adding a further detail or example. Fix: practice
> extending long-turn answers with a specific example when I finish
> early."

This style of self-assessment identifies a specific, fixable pattern
per section rather than a vague overall impression ("I think I did
okay").

## 6. Cheat sheet — capstone mock test checklist

| Check | Why it matters |
|---|---|
| Did I time every section exactly as the real exam does? | Untimed practice doesn't reveal your real exam-day performance |
| Did I record my Speaking section for review? | Self-assessing speaking from memory is unreliable |
| Did I self-assess against band descriptors, not just a gut feeling? | Descriptor-based review reveals specific, fixable gaps |
| Did I write down one specific fix per section, not just a score? | A score alone doesn't tell you what to practice next |

## Exercise

Administer a full timed mock test using unseen material across all
four sections in one sitting. Score Listening and Reading against an
answer key, self-assess Writing and Speaking against the Band
descriptors in section 3, and write a short self-assessment note (as
in section 5) with one specific, fixable pattern identified per
section. This is the final deliverable for Level 4.
