# 09 · Giving a 3-5 Minute Structured Talk

Level 1 built a 2-minute short talk. This module extends that to a
**3-5 minute structured talk** — long enough that a simple
opening-middle-end shape isn't enough on its own; you need explicit
signposting to keep a listener oriented and enough content depth to
sustain several minutes without repeating yourself.

## 1. Why longer talks need more structure

A 2-minute talk can survive on a rough shape held in your head. At 3-5
minutes, a listener loses track of where you are unless you tell them —
and you, as the speaker, are more likely to run out of planned content
and start repeating points. Both problems are solved the same way:
explicit structure.

## 2. A five-part structure for longer talks

| Part | Purpose | Approx. length |
|---|---|---|
| 1. Hook/intro | Grab attention, state the topic | 20-30s |
| 2. Roadmap | Tell the listener what points you'll cover, in order | 15-20s |
| 3. Point 1 (with example) | First main idea, fully developed | 45-60s |
| 4. Point 2 (with example) | Second main idea, fully developed | 45-60s |
| 5. Point 3 + conclusion | Third idea + wrap-up, restating the main message | 45-60s |

The **roadmap** step is what separates this from a Level 1 short talk —
explicitly saying "I want to cover three things: first X, then Y, and
finally Z" gives the listener a mental map to follow for the next
several minutes.

## 3. Signposting language

| Function | Phrases |
|---|---|
| Announcing structure | "I want to cover three main points today," "Let's start with..." |
| Moving to the next point | "Moving on to...", "The second thing I'd like to mention is...", "That brings me to..." |
| Giving an example | "For instance...", "A good example of this is...", "To illustrate..." |
| Returning to the main thread | "Going back to what I said earlier...", "As I mentioned..." |
| Concluding | "So, to sum up...", "The main takeaway here is...", "In short..." |

Signposting phrases cost almost nothing in content but do enormous work
for Coherence — they're one of the highest-value additions at this
level.

## 4. Worked example — outline for a 4-minute talk

> **Topic: Why I think learning a second language is worth the effort**

> **Hook:** "I want to talk today about something I get asked a lot:
> whether it's really worth the time to learn a second language as an
> adult. My answer is yes, and I want to explain why through three
> points."
>
> **Roadmap:** "I'll talk about the practical benefits, then the
> cognitive benefits, and finally the personal, emotional side of it."
>
> **Point 1 (practical):** Career opportunities, travel, access to more
> information — with a specific example (a colleague who got a
> promotion partly because of a second language).
>
> **Point 2 (cognitive):** Improved memory and multitasking, delayed
> cognitive decline — reference a general, well-known finding (without
> overstating it as fact) and a personal observation.
>
> **Point 3 (emotional) + conclusion:** Confidence, connecting with
> people from other cultures — closing with "So while it takes real
> effort, I think the payoff — practically, mentally, and personally —
> makes it more than worthwhile."

Notice each point gets a clear signal ("first," "second," "finally")
and the conclusion explicitly restates the three points before ending.

## 5. Cheat sheet — longer talk checklist

| Check | Why it matters |
|---|---|
| Did I state a roadmap near the start? | Orients the listener for a multi-minute talk |
| Did I use a signpost phrase before each new point? | Makes structure audible, not just present in your head |
| Did each point include a concrete example? | Prevents the talk from sounding like a list of abstract claims |
| Did my conclusion restate the main points, not just stop? | A proper close is expected at this length |
| Did I hit close to the 3-5 minute target? | Under 3 minutes suggests underdeveloped points; well over 5 suggests poor time control |

## Exercise

Choose a topic you know well and outline it using the five-part
structure in section 2, writing only short phrases for each part (not
full sentences). Record yourself delivering the talk aloud, aiming for
3-5 minutes, using at least four signposting phrases from section 3.
Play it back and check it against the section 5 checklist.
