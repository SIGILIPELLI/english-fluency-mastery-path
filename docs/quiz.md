### Analyse a spoken answer

Write analyse(transcript, seconds) to compute the word count, words per minute, filler-word count and filler rate (percent), and the type-token ratio (distinct words divided by total words). It's the kind of measurement you can run on your own recorded talk.

**Starter code**

```python
import re

FILLERS = {"um", "uh", "er", "like", "basically", "actually"}

def analyse(transcript, seconds):
    # return a dict with: words, wpm (rounded), fillers (count of FILLERS), filler_rate (% rounded to 1 d.p.)
    # and ttr (distinct words / total words, rounded to 2 d.p.). Words = letters and apostrophes, lowercased.
    return {}

talk = ("Um I would like to talk about a person who has influenced me. Basically my aunt, "
        "she taught me to be patient, and actually she taught me to listen. Like when I was "
        "young I was very impatient but she showed me how to listen carefully.")
print(analyse(talk, 30))
```

**Expected output**

```text
{'words': 46, 'wpm': 92, 'fillers': 5, 'filler_rate': 10.9, 'ttr': 0.7}
```

<details><summary>Show solution and explanation</summary>

<pre><code>import re

FILLERS = {&quot;um&quot;, &quot;uh&quot;, &quot;er&quot;, &quot;like&quot;, &quot;basically&quot;, &quot;actually&quot;}

def analyse(transcript, seconds):
    words = re.findall(r&quot;[a-zA-Z&#x27;]+&quot;, transcript.lower())
    fillers = [w for w in words if w in FILLERS]
    wpm = len(words) / (seconds / 60)
    ttr = len(set(words)) / len(words)           # lexical variety (type-token ratio)
    return {
        &quot;words&quot;: len(words),
        &quot;wpm&quot;: round(wpm),
        &quot;fillers&quot;: len(fillers),
        &quot;filler_rate&quot;: round(100 * len(fillers) / len(words), 1),
        &quot;ttr&quot;: round(ttr, 2),
    }

talk = (&quot;Um I would like to talk about a person who has influenced me. Basically my aunt, &quot;
        &quot;she taught me to be patient, and actually she taught me to listen. Like when I was &quot;
        &quot;young I was very impatient but she showed me how to listen carefully.&quot;)
print(analyse(talk, 30))
</code></pre>

<p>Measuring pace, fillers and lexical variety turns &#x27;I think I did okay&#x27; into evidence you can improve against. These are rough proxies, not official band scores. Verified by running the solution.</p>
</details>

### Check an IELTS essay's basics

Write check_essay(text, task): Task 1 needs at least 150 words and an overview word (overall, in summary, to summarise); Task 2 needs at least 250 words and at least four paragraphs separated by blank lines. Return a list of problems or ['ok'].

**Starter code**

```python
import re

def check_essay(text, task):
    # task1 needs >= 150 words and an overview word (overall / in summary / to summarise);
    # task2 needs >= 250 words and at least 4 paragraphs (separated by blank lines).
    # return a list of problem strings, or ["ok"]
    return []

essay = ("Some people think museums should be free. I partly agree.\n\n"
         "Free entry increases access for everyone. " * 5 + "\n\n"
         "However, funding is a concern. " * 5)
print(check_essay(essay, "task2"))
report = "The chart shows sales in four regions. " * 8 + "Overall, the north was highest."
print(check_essay(report, "task1"))
print(check_essay("The graph rises.", "task1"))
```

**Expected output**

```text
['under word count (105/250)']
['under word count (61/150)']
['under word count (3/150)', 'no overview sentence']
```

<details><summary>Show solution and explanation</summary>

<pre><code>import re

def check_essay(text, task):
    minimum = {&quot;task1&quot;: 150, &quot;task2&quot;: 250}[task]
    words = re.findall(r&quot;[A-Za-z&#x27;]+&quot;, text)
    paragraphs = [p for p in re.split(r&quot;\n\s*\n&quot;, text.strip()) if p.strip()]
    problems = []
    if len(words) &lt; minimum:
        problems.append(f&quot;under word count ({len(words)}/{minimum})&quot;)
    if task == &quot;task2&quot; and len(paragraphs) &lt; 4:
        problems.append(&quot;needs introduction, body paragraphs and conclusion (at least 4 paragraphs)&quot;)
    if task == &quot;task1&quot; and not re.search(r&quot;\b(overall|in summary|to summarise|to summarize)\b&quot;, text.lower()):
        problems.append(&quot;no overview sentence&quot;)
    return problems or [&quot;ok&quot;]

essay = (&quot;Some people think museums should be free. I partly agree.\n\n&quot;
         &quot;Free entry increases access for everyone. &quot; * 5 + &quot;\n\n&quot;
         &quot;However, funding is a concern. &quot; * 5)
print(check_essay(essay, &quot;task2&quot;))
report = &quot;The chart shows sales in four regions. &quot; * 8 + &quot;Overall, the north was highest.&quot;
print(check_essay(report, &quot;task1&quot;))
print(check_essay(&quot;The graph rises.&quot;, &quot;task1&quot;))
</code></pre>

<p>Meeting length and structure requirements is the floor, not the ceiling: the band depends on task response, coherence, vocabulary and grammar. This checker only catches basic omissions. Verified by running the solution.</p>
